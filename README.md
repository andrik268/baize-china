# Бай Цзэ

Сайт-визитка с каталогом образовательных и каникулярных программ в Китае.

## Запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```

Формы сейчас работают как интерфейсный прототип. Для продуктивного приёма заявок подключите CRM или serverless endpoint. Изображения поездок сгенерированы как временные брендовые материалы и подготовлены к замене реальными фото клиента.

## Визуальная система

Финальная палитра объединяет терракотовые заголовки с ярко-синими кнопками и блоком «О компании». На странице одна согласованная версия без переключателя цветов.

В сайт также добавлены FAQ по обучению в Китае, блок для будущих видео и скриншотов отзывов, ссылки MAX и ВКонтакте.
