# Бай Цзэ

Сайт-визитка с каталогом образовательных и каникулярных программ в Китае.

## Запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```

Формы сейчас работают как интерфейсный прототип. Для продуктивного приёма заявок подключите CRM или serverless endpoint. Изображения поездок сгенерированы как временные брендовые материалы и подготовлены к замене реальными фото клиента.

## Цветовые варианты

По умолчанию используется терракотовая палитра, которая лучше связывает сайт с Китаем и сохраняет деловой тон. Для просмотра альтернатив на продакшн-адресе добавьте query-параметр:

- `?palette=terracotta` - терракотовый и сланцевый
- `?palette=jade` - нефритовый и графитовый
- `?palette=vermilion` - киноварный и серо-коричневый

В сайт также добавлены FAQ по обучению в Китае, разделы «Отзывы» и «Кейсы», ссылки MAX и ВКонтакте.
